and avoid tripping any security monitoring rules, thus alerting any victims to the attempted compromise.</p> <h2 class="wp-block-heading">Our Recommendations</h2> <p></p> <ul class="wp-block-list"> <li>Avoid downloading pirated software from unverified sites.</li> <li>Use strong passwords and enforce <a href="/blog/multi-factor-authentication-mfa-is-a-part-of-your-cyber-hygiene/" Growing Concern for Internet Security" target="_blank" rel="noopener" data-wpil-monitor-id="13620">internet security</a> software package on your connected devices, including PC, laptop, and mobile. </li> <li>Refrain from opening untrusted links and email attachments without first verifying their authenticity. </li> <li>Block URLs that could be used to spread the malware, e.g., Torrent/Warez. During a routine threat-hunting exercise, we came across a Twitter post where a researcher mentioned a fake Atomic wallet site distributing Mars Stealer. Figure 6 \u2013 Hiding the .exe file using the attrib command        Then, the .bat file executes PowerShell content using AtomicWallet_Setup.bat.exe, which further decodes the base64-encoded content and decrypts it using an AES algorithm that stores a Gzip Compressed stream in the memory. Figure 7 \u2013 Code for AES Decryption and GZip Decompression        Finally, the malware decompresses the GZip content and loads the final PowerShell code that downloads Mars Stealer from the Discord server to the victim's %LOCALAPPDATA% location.        Figure 8 \u2013 Downloading Mars Stealer from the Discord server        The below figure shows the infection chain of Mars Stealer. Figure 9 \u2013 Infection chain        After successful installation, Mars Stealer steals sensitive information from the victim's device and exfiltrates the stolen data to the C&amp;C server.
